### Basic Integration:
```jsx

<div className="score-card">
  <p className="score-number">750</p>
</div>

// 2. Apply tier colors
<div className={`tier-badge tier-${getTier(score)}`}>

</div>

// 3. Combine components

  <ScoreCard score={750} />
```
